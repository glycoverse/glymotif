# glymotif: Extract Glycan Motifs from Glycan Structures

Identify, count, and match recurring substructures in glycan structures.
Supports concrete and generic monosaccharide matching, several
structural alignment modes, node-to-node mappings, and batch analysis
using subgraph isomorphism. Includes curated motif annotations derived
from the 'GlycoMotif' resource <https://glycomotif.glyomics.org/>.
Integrates with 'glyrepr' and 'glyparse' for structural glycomics
workflows.
